# TIRAJ ENTERPRISE UI update

This version updates the storefront UI to a polished ecommerce layout inspired by the supplied Venux reference: announcement bar, navigation, hero, benefits, compatibility brands, product cards, feature sections, FAQ, story section, footer and a functional client-side cart drawer.

## Run locally

1. Open this folder in a terminal.
2. Install dependencies:
   `npm install`
3. Copy `.env.example` to `.env.local` and add the required environment values.
4. Start the development server:
   `npm run dev`
5. Open `http://localhost:3000`.

The existing API, Prisma schema and admin route were left in place. This update focuses on the storefront UI and client-side cart presentation.
